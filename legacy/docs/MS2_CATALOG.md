# Current MS3 song catalog

The active score is documented in [MS3_SONG_DIRECTION.md](MS3_SONG_DIRECTION.md), with exact source lineage in [MS3_SONG_AUDIT.json](MS3_SONG_AUDIT.json). `MS2_CATALOG.json`, `MS2_CLIPS.zip` and the `ms2` runtime folder retain compatible historical filenames. They now contain complete source-ordered song delivery chunks, not randomly selected sixteen-bar excerpts. Historical sixteen-bar curation evidence remains in `MS3_16_BAR_AUDIT.json` and `validation/MS3_LONGFORM.md`; it is not the active selection policy.
