The Surge backbone supersedes the live-synth implementation described below. Current implementation, render-bank evidence and pending native acceptance are in [MS2_SURGE.md](MS2_SURGE.md). Prior native console-enabled audibility belongs to the former backend.

The author supplied `LoD MIDI Library.zip`, archive SHA-256 `bec1b20a195176d373b6ca0740405d0aafb0d54c2eede02a5017527f43e4be7d`, and explicitly authorized MS2 design changes, cleanup and GitHub publication.

Compiled catalog revision `ms2-be9489d0c3ba99c7`: 465 deduplicated MIDI stems, eight blocks, 48 arrangements, 1,402 phrases, 170,860 notes. All six roles are supplied for every block; the two MP3-named Stems archives also contain MIDI. Runtime content includes only compiled notes/engine and short synthesized fallback tones, not recordings. [Direction](../MS2_CATALOG.md), [complete catalog](../MS2_CATALOG.json), and [portable MIDI clips](../MS2_CLIPS.zip) preserve the bank and its provenance.

Finite source scope: the actual MIDI reader/compiler and byte-identical saved-source rebuild, every shard/phrase/mode/successor, portable MIDI export, composer mutations/fills/transport/stalls, server/client permission and plan lifecycle, victory receipt replay guards, private block announcements, native bank/voice limits, frame-pressure reduction and affected controls/timer/boss/logger/manual/VR regressions. `tools/test_music_gate.py` records every selected suite, logs, source SHA-256 before/after and all Lua syntax. This is a targeted integration gate, not the full campaign matrix. Final results are in `MS2_CHECKS.json`: 41/41 selected suites, 880 Lua syntax checks and identical source before/after. Acorn also parses the production engine as ES5; the largest LZMA-compressed distributed Lua file is 42,539 bytes, within AddCSLuaFile’s limit.

The real Chromium OfflineAudioContext test uses the production engine, rendered output for all 48 arrangements and all nine instruments, then a 36-second score spanning calm, tension, two-floor fade/reversal, reduced quality, critical boss expression, fanfare/Chill and Off. The observed output is finite and unclipped; no silent 100 ms window occurs during the active transition sequence. Off gives digital silence and zero remaining lanes. Each instrument is audible; note admissions remain at or below 24. Exact measurements are in `MS2_AUDIO.json`. An optional [36-second audition](MS2_AUDITION.ogg) demonstrates this scripted progression; it is an offline renderer recording, not in-game audio capture.
